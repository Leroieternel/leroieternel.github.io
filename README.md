# Mobile manipulation films

The [Workcell Safety viewer](https://mcxiangalds.com/workcell-safety/#mobile_roastery) pairs each film with its robot plans, measured trajectory, event time and contact-force data.

Each folder contains safe and unsafe H.264 replays at 1920 × 1080 and a synchronized 3840 × 1080 comparison. All three play at 25 frames per second. The robot and objects replay recorded MuJoCo poses. Blender Cycles renders the rooms and lighting.

The films use Agibot World Genie Sim materials and are shared under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). See [model and material credits](https://mcxiangalds.com/workcell-safety/mobile-materials.html) for the individual assets and adaptations.
