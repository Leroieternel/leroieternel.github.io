Evaluation protocol

All 16 conditions use identical ground truth, atomic-action keys, cutoff positions, and image indices: 75 parent episodes, 265 atomic actions, and six causal cutoffs (25%, 40%, 55%, 70%, 85%, 95%). Each input contains four synchronized and chronologically ordered front-view/wrist-view image pairs. SentenceBERT is cosine similarity from sentence-transformers/all-mpnet-base-v2. Higher is better for every metric.
